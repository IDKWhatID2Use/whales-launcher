# WhalesLauncher v1.0.2 —— 外壳左栏改为「功能列表」

DeepSeek Harness (dsh) 的实例与版本管理启动器。本版是一次**界面信息架构修正**：
左栏从「实例列表 + 两个底部入口」改为**固定的功能列表**，实例列表只保留在「实例」页内。

## 下载

| 文件 | 说明 |
|---|---|
| `WhalesLauncher-v1.0.2-win-x64.zip` | **完整应用**（89.31 MB，解压即用） |

解压后双击包内的 `WhalesLauncher.exe` 即可运行。**不需要安装 .NET 运行时**（已自包含）。

## 环境要求

- **Windows 10 1809（10.0.17763）或更高，64 位**
- **Node.js 不需要你预装** —— 本机已有的会被优先沿用；一个都没有时，启动器会**自动下载
  官方 Node v22 LTS 便携版**（约 30MB，校验官方 SHA-256，解压到 `<启动器根>\runtime\node\`，
  免管理员权限、不改系统设置，且自带 npm）

首次启动会跑一次**环境与依赖自检**，自动处理掉大部分"本该由你动手"的事：

| 情况 | 启动器的动作 |
|---|---|
| 数据目录（`instances` / `engines` / `shared` / `cache`）不存在 | **自动创建**，并做一次写探针确认可写 |
| 本机没有任何 dsh 引擎 | 问一次后**自动用 npm 安装**最新版（联网、数百 MB、不可中途取消） |
| 本机没有任何可用的 Node.js | 问一次后**自动下载官方便携版**（约 30MB，免管理员权限） |
| 全局配置缺失 / 损坏 | 自动生成默认值；损坏的改名备份，不静默丢设置 |

如果你自己装过 Node，它会**优先沿用你的**：按 `$WHALES_NODE_PATH` → 配置里的 `nodePath`
→ 系统 `PATH` → 常见安装位置的顺序探测，每个候选都**实际执行一次探针**验证，绝不按路径名
猜测。也可以随时在「全局设置 → Node 运行时」里手动指定（自备便携版排在这些来源**之后**）。

> ⚠️ 不要用非官方 Node 运行时去跑 dsh：dsh 的原生模块按运行时指纹白名单匹配，
> 非官方指纹会直接启动失败（`node-addon-require-builtin unsupported`）。

## 本次修正（相对 v1.0.1）

### 1. 外壳左栏改为功能列表（消除用户指出的功能重复）

- 左栏现在是固定四项：**实例 / 引擎版本管理 / 全局设置**，底部固定**关于**。
- 实例列表**只保留在「实例」页内** —— 卡片网格、页内搜索 / 状态筛选 / 排序全部照原样。
  此前同一批实例数据同时出现在左栏和内容区（底部还另有一份「引擎版本管理 / 全局设置」），
  是用户明确指出的**功能重复**。
- 左栏顶部的「筛选实例」输入框删除（与实例页内的搜索框重复）。
- **顺带修掉两个已登记的缺陷**：
  - 「实例」项在实例列表页与详情页都会点亮 —— P1 首屏左栏不再没有高亮；
  - 返回按钮恢复规范语义（只在详情页出现）。旧版因为左栏没有「实例列表」入口，
    不得不把返回按钮放宽成"任何非首屏路由且可后退"；现在任意页面都能从「实例」项
    一键回到实例列表。
- 新增**「关于」页**（左栏底部固定项），显示启动器版本、界面框架、Node 运行时、
  已安装 dsh 引擎与存储位置。

### 2. 详情页面包屑可点击

面包屑改为三段「实例 › 实例名 › 页名」：第一段回实例列表、第二段回该实例的默认页签
（插件）、末段（当前页名）不跳转。

### 3. 验收阶段发现并修复的两处界面问题

| 问题 | 处理 |
|---|---|
| 关于页把许可证写成 MIT | 实际是 **Polyform Noncommercial License 1.0.0**（仓库 `LICENSE` 与 `README` 一致），已改为准确表述，并点明该许可证不是 OSI 认证的开源许可证 |
| **深色模式下标题栏右上角三个窗口按钮几乎不可见** | 这三个按钮由**系统**按**系统主题**绘制，不跟随窗口内容主题；深色窗口跑在浅色系统上时字形与标题栏同为暗色。现在按**当前生效主题**显式配色（深色白字形 / 浅色黑字形，背景透明），已实测确认 |

### 4. 自动化与工具

- UI 自动化用例：左栏相关断言改为按 `AutomationProperties.Name` **精确匹配**（不再靠
  "文本出现在子树里"）；新增 **SH-10**（功能页 ↔ 实例页互跳，旧左栏没有实例入口的回归保护）
  与 **SH-11**（「关于」是可导航页面而非弹框）；**SH-09** 改为负向断言（筛选框必须不存在）。
  全套 **73 断言 / 0 失败**。
- 修掉三处**测试基建**缺陷（都不是本版功能改动引入的，但会让用例红得莫名其妙）：
  1. UIA 的 `FindAll` 在窗口重绘时会瞬时抛异常，一个异常带崩整个用例 → 退回 TreeWalker 兜底；
  2. 该驱动的 `FindAll` 对子作用域返回的结果并不完整 → 改为 `FindAll` + TreeWalker
     **合并去重**，查找不再取决于当帧拿到哪种形状；
  3. 用例进程继承上游环境变量可能让应用静默打开别的页面 → runner 显式清理路由相关变量。

### 5. 新增「环境与依赖自检」—— 把"要你自己动手"的部分接过来

首次启动自动跑一次，之后每次启动只做**本地**检查（不再联网），随时可在
**全局设置 → 环境自检** 重跑完整自检；报告逐项给出结论（正常 / 已自动修复 / 缺失 /
失败 / 未检查），缺失项带下一步建议。

| 情况 | 启动器的动作 |
|---|---|
| 数据目录（`instances` / `engines` / `shared` / `cache`）不存在 | 自动创建，并做一次写探针确认真可写 |
| 本机没有任何 dsh 引擎 | 问一次后自动用 npm 安装最新版（联网、数百 MB、不可中途取消） |
| 本机没有任何可用的 Node.js | 问一次后**自动下载官方 v22 LTS 便携版**（约 30MB，校验官方 SHA-256，落在 `<根>\runtime\node\`，免管理员权限、不改系统设置、自带 npm；官方源不可达时回退 npmmirror 镜像） |
| 全局配置缺失 / 损坏 | 自动生成默认值；损坏的改名备份，不静默丢设置 |

> 探测到的**已有 Node 永远优先被沿用**，自备便携版排在各来源之后 —— 它只是"一个都没有"时的兜底。
