改动要点

  1. 左栏由「实例列表」换成功能列表：实例 / 引擎版本管理 / 全局设置，关于固定在底部。
  2. 实例列表移入「实例」页：卡片网格原样保留，搜索 / 状态筛选 / 排序也都在页内。
  3. 左栏顶部的「筛选实例」框取消——它与页内搜索框重复；左栏因此只承担"去哪一页"。
  4. 实例详情成为「实例」功能下的下钻页：左栏仍选中「实例」，页首加面包屑 实例 › 实例名 › 页签。
  5. 附带修好一处已知问题：现在从引擎 / 设置页总有路径回到实例列表（旧左栏没有"实例列表"入口）。

图标与颜色

  1. 三个功能图标统一为 16 px 描边风格（1.25 px），设置换成标准齿轮轮廓（原来那条手绘多边形是错的）。
  2. 选中项只染左侧 3 px 指示条，图标保持主文字色 —— WinUI NavigationView 就是这样，也避免深色主题下出现一枚突兀的亮色图标。
  3. 图标全部用 currentColor，深浅两套主题自动跟随。
  4. 实例头像的色底改成 实例色的 10% 透明淡底（与真实实现 InstanceCardPaint.Tint 的 0x1A 同源）—— 之前演示稿写成不透明浅色 hex，深色模式下是一块亮色方块，淡色文字几乎看不见。
