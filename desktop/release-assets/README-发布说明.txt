WhalesLauncher —— 使用说明
============================================================

本压缩包是 WhalesLauncher 的**官方发布成品**，已自带运行库，
**不需要安装 .NET 或任何其他依赖**。


一、怎么运行
------------------------------------------------------------

有两种方式，任选其一：

  1) 双击本目录下的  WhalesLauncher.exe
     —— 最直接的方式。

  2) 双击本目录下的  启动 WhalesLauncher.bat
     —— 与上面等价，但会保留一个控制台窗口，
        启动失败时能在窗口里看到原因（排查问题用）。

首次启动可能会慢几秒（系统在预热运行库），属正常现象。


二、需要什么
------------------------------------------------------------

  * Windows 10 1809（10.0.17763）及以上，64 位
  * Node.js 22 或更高版本  ← **这一项必须自行安装**

关于 Node.js 的说明（重要）：

  WhalesLauncher 是一个启动器。它自己的界面不需要 Node，
  但要**管理 dsh 实例**就必须有一个真正的 Node.js：

      https://nodejs.org/

  程序启动时会自动探测 Node，顺序为：

      $WHALES_NODE_PATH  →  配置里的 nodePath  →  系统 PATH
                         →  常见安装位置（nvm-windows / Volta / fnm 等）

  每个候选都会**实际执行一次探针**验证，绝不按路径名猜测。
  如果没探到，界面仍然能打开，但会明确提示"后端未就绪"，
  并且可以在「全局设置 → Node 运行时」里手动指定 node.exe。

  注意：请**不要**用非官方 Node 运行时（如某些软件内置的 Node）去跑 dsh ——
  dsh 的原生模块按运行时指纹白名单匹配，非官方指纹会直接启动失败
  （报 node-addon-require-builtin unsupported）。


三、数据放在哪
------------------------------------------------------------

首次运行会在程序同目录（或你指定的位置）生成：

  launcher.json   运行配置（主 home、Node 路径等）
  instances/      各个 dsh 实例
  engines/        下载的引擎版本
  logs/           运行日志
  cache/          端口台账等缓存

想换位置：设置环境变量  WHALES_LAUNCHER_ROOT 指向目标目录即可
（例如放到 D:\WhalesData 这种不属于程序目录的地方，便于升级时保留数据）。

**升级提示**：把新版本解压到别的目录、或覆盖程序文件即可，
只要数据目录不在程序目录内，数据就不会丢。


四、入门
------------------------------------------------------------

  1. 装好 Node.js 22+
  2. 双击 WhalesLauncher.exe
  3. 左栏底部「引擎版本管理」→ 安装一个 dsh 引擎版本
     （需要联网，从 npm registry 拉取）
  4. 「新建实例」→ 四步向导（名称与外观 / 引擎版本 / profile 模板 / 隔离策略）
  5. 回到实例列表，点「启动」

完整图文教程见仓库：
  https://github.com/IDKWhatID2Use/whales-launcher/blob/main/docs/guide/README.md


五、出问题了怎么办
------------------------------------------------------------

  1. 先双击  启动 WhalesLauncher.bat  看控制台输出
  2. 再看  logs/  目录下的日志
  3. 若启动瞬间就失败，程序目录里可能出现 crash.txt，
     里面有异常堆栈，请一并附上

常见情况：

  * 界面能开但没有数据
    → 没探到 Node.js。见上文第二节，或到「全局设置 → Node 运行时」手动指定。

  * 实例启动失败，提示 node-addon-require-builtin unsupported
    → 用非官方 Node 运行时跑了 dsh。换成 nodejs.org 的官方版本。

  * 实例启动失败，提示端口被占用（EADDRINUSE 3080）
    → 启动器会自动避让端口（3080–3179）；若整个区间被占满，
      可在实例设置里手写一个 --port。


六、这个包是怎么来的
------------------------------------------------------------

  * 前端：WinUI 3（C#/XAML）+ Windows App SDK，原生控件与系统主题资源
  * 业务引擎：原 TypeScript 引擎（src/core）由 Node 侧车进程承载
  * 打包形态：.NET 自包含发布（win-x64），故无需预装 .NET 运行时
  * 源码：https://github.com/IDKWhatID2Use/whales-launcher
